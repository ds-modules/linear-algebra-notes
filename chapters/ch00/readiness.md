# 0.1 Mathematical Readiness

Linear algebra uses familiar algebra in a new setting. The ideas in this book do not require calculus, but the following skills will make the first sections much easier:

- arithmetic with negative numbers and fractions,
- the distributive property and combining like terms,
- solving a one-variable equation,
- substituting a value into an expression, and
- reading points and lines on a coordinate plane.

The checks below are a refresher, not an assignment. Try each one mentally, then expand the solution.

## Signed numbers and fractions

Evaluate

$$
-3 + 5,\qquad 4-(-2),\qquad \frac{2}{3}+\frac{1}{6}.
$$

````{admonition} Solution
:class: dropdown

$$
2,\qquad 6,\qquad \frac{5}{6}.
$$

For the fraction sum, use sixths: $\frac{2}{3}=\frac{4}{6}$.
````

## Distributing and combining terms

Simplify $3(2x-1)-4x$.

````{admonition} Solution
:class: dropdown

$$
3(2x-1)-4x=6x-3-4x=2x-3.
$$
````

## Solving an equation

Solve $3x-5=10$.

````{admonition} Solution
:class: dropdown

Add $5$ to both sides and then divide by $3$:

$$
3x=15 \quad\Longrightarrow\quad x=5.
$$
````

## Substitution

If $x=2$ and $y=-1$, evaluate $3x-2y$.

````{admonition} Solution
:class: dropdown

$$
3(2)-2(-1)=6+2=8.
$$
````

## Coordinates and lines

Does the point $(2,1)$ lie on the line $x+y=3$?

````{admonition} Solution
:class: dropdown

Yes. Substitution gives $2+1=3$, so the point satisfies the equation.
````

```{tip}
Fractions and negative signs appear often during elimination. If one of these checks was difficult, review that skill before Section 1; it is arithmetic preparation, not a linear-algebra barrier.
```
