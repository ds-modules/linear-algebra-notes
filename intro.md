# Linear Algebra Notes

An interactive textbook for **linear algebra for data science**, organized around Math 279 (LACC) and enriched with ideas from Math 56 and EECS 16A.

## How to read this book

This is a **demo textbook**, not a lab notebook.

- Read sections in order; later ideas build on earlier ones.
- Code cells are **illustrations** with outputs already computed — not worksheets to edit for credit.
- Interactive demos run in the page without a Binder kernel or local environment.
- Section **0** is an optional review of the algebra and coding background used later.
