Systems of Linear Equations: The Foundation of Linear Algebra

A system of linear equations is a collection of one or more linear equations involving the same variables. Linear equations are fundamental to data science as they allow us to model relationships between variables and solve for unknown values.

Solution to a System

A solution to a system of linear equations is an ordered set of values for the variables that satisfies all equations in the system simultaneously. A system can have:

  • Exactly one solution (consistent and independent)
  • Infinitely many solutions (consistent and dependent)
  • No solution (inconsistent)

Gaussian Elimination

Gaussian elimination is a systematic method for solving systems of linear equations by transforming the augmented matrix into row echelon form.

Elementary Row Operations

We can perform three types of elementary row operations without changing the solution set:

  1. Interchange two rows: Switch the positions of two equations.
  2. Multiply a row by a nonzero constant/Row scaling: Multiply all terms in an equation by the same nonzero number. where
  3. Add a multiple of one row to another: Add a multiple of one equation to another equation.

Row Echelon Form (REF)

A matrix is in row echelon form when:

  • All rows consisting entirely of zeros are at the bottom
  • The pivot or leading entry (first nonzero element) of each nonzero row is 1
  • Each pivot is in a column to the right of the pivot in the row above it

Gauss-Jordan Elimination

Gauss-Jordan elimination extends Gaussian elimination by continuing to perform row operations until the matrix is in reduced row echelon form.

Reduced Row Echelon Form (RREF)

A matrix is in reduced row echelon form when:

  • It is in row echelon form
  • Every leading entry is 1
  • Each leading 1 is the only nonzero entry in its column

Homogeneous Systems of Linear Equations

A homogeneous system of linear equations is a system where all constant terms are zero. In other words, it is a system of the form Ax = 0, where A is the coefficient matrix, x is the vector of variables, and 0 is the zero vector.

Solving Homogeneous Systems

Homogeneous systems are solved using the same row reduction techniques (Gaussian or Gauss-Jordan elimination) as non-homogeneous systems. The key difference is in interpreting the results:

  • If the number of pivot positions equals the number of variables (n), then the only solution is the trivial solution x = 0.
  • If the number of pivot positions is less than the number of variables, then the system has infinitely many solutions, including the trivial solution.

Row-wise interpretation

In a system of m equations with n variables, each row represents one equation or observation. Each row is a constraint. The solution is the point where all these hyperplanes intersect. This corresponds to the observation-based view. For instance, in linear regression, each row is a data sample, and solving the system means finding parameters that satisfy all sample observations.

and 

In the matrix-vector notation, this corresponds to comparing the multiplication of the row vector of coefficient matrix and the variable vector against each element of the constant vector.

Column-wise interpretation

The left-hand side of the matrix-vector notation can be thought of as computing the linear combination of the column vectors of the coefficient matrix A with the variables serving as linear weights. Solving linear equations gives the linear weights needed to produce the constant vector.

This corresponds to the feature-based view. Each column represents a feature, and the solution determines how to combine features.

Applications in Data Science

Systems of linear equations form the backbone of linear algebra, which is crucial for uncovering hidden patterns and relationships within datasets. They are foundational to many data science applications:

Linear Regression

In linear regression, we solve systems of linear equations to find the line of best fit for a dataset to predict outcomes based on input features.

Machine Learning and AI

Used in algorithms like Support Vector Machines (SVM) to establish decision boundaries, and in neural networks for image processing and classification. 

Feature Transformation

Linear transformations, represented by matrix multiplication, are used to transform data features. 

Optimization

Solving for resource allocation and logistics, such as transportation routing, to maximize efficiency.

Dimensionality Reduction

Principal Component Analysis (PCA) uses systems of linear equations to find the eigenvectors and eigenvalues of the covariance matrix. Linear algebra, including systems of equations, is used to identify essential features and reduce data complexity.
