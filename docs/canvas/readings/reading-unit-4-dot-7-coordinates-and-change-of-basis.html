Coordinates and Change of Basis

Introduction

Coordinates and basis transformations are fundamental concepts in linear algebra that allow us to represent vectors in different reference frames. Just as we can describe a location using different coordinate systems (Cartesian, polar, etc.), we can represent vectors using different bases. The ability to change between coordinate systems provides powerful tools for simplifying problems and revealing hidden structure in data.

In data science, these concepts underlie many important techniques, including dimensionality reduction, feature transformation, and signal processing. Understanding coordinates and change of basis helps us develop more efficient representations of data, identify patterns, and implement algorithms that work in the most appropriate coordinate system for a given problem.

Different bases provide different perspectives on the same vector space. Choosing the right basis can simplify calculations, reveal underlying patterns, and provide meaningful interpretations of data.

Other Common Bases

Different applications often use different bases:

  • Polynomial Basis: {1, x, x2, ..., xn} for the space of polynomials of degree ≤ n
  • Fourier Basis: {1, sin(x), cos(x), sin(2x), cos(2x), ...} for the space of periodic functions
  • Wavelet Basis: Used for time-frequency localization in signal processing
  • Principal Component Basis: Eigenvectors of the covariance matrix, used in PCA

Applications in Data Science

Principal Component Analysis (PCA)

PCA is a classic example of a change of basis in data science:

  • Starting with data in the standard basis, PCA finds a new basis aligned with the directions of maximum variance
  • The new basis consists of the eigenvectors of the covariance matrix
  • The change of basis matrix is formed by these eigenvectors
  • Transforming data to this new basis separates the variance components and enables dimensionality reduction

Feature Engineering and Transformation

Feature engineering often involves changing the basis of the data:

  • Polynomial Features: Transforming from the standard basis to a polynomial basis
  • Fourier Transform: Changing from the time domain to the frequency domain basis
  • Wavelet Transform: Moving to a basis that provides time-frequency localization
  • Kernel Methods: Implicitly transforming to a higher-dimensional basis where data becomes linearly separable

Signal Processing

Different bases are used for different signal processing tasks:

  • Fourier Basis: For frequency analysis and filtering
  • Wavelet Basis: For multi-resolution analysis, denoising, and compression
  • DCT Basis: Used in JPEG compression to represent image blocks efficiently

Recommendation Systems

Matrix factorization techniques in recommendation systems can be viewed as finding a new basis:

  • The user-item interaction matrix is decomposed into user factors and item factors
  • These factors form a lower-dimensional basis that captures latent features
  • Recommendations are made by projecting users and items onto this basis

Real-World Example: In image recognition, convolutional neural networks (CNNs) learn filters that essentially form a new basis for representing images. The early layers capture basic features like edges and textures, while deeper layers represent more complex patterns. This hierarchical basis transformation allows CNNs to effectively recognize complex objects in images.
